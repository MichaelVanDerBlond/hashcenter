===============================================================================
Обновление документации
===============================================================================

Любое изменение архитектуры проекта должно сопровождаться обновлением
соответствующих документов.

Документация считается частью исходного кода проекта.

Pull Request, изменяющий архитектуру без обновления документации,
не может считаться завершённым.

===============================================================================
Главный принцип
===============================================================================

Если код противоречит документации —
необходимо определить, что устарело.

Либо обновляется документация,

либо исправляется код.

Документация и исходный код должны оставаться согласованными.
