# HashCenter Project Registry

Version: R0.1

-------------------------------------------------------------------------------
# Назначение

PROJECT_REGISTRY является официальным реестром всех подсистем HashCenter.

Любая новая подсистема должна быть зарегистрирована здесь до начала разработки.

Любая удалённая подсистема должна быть помечена как Deprecated.

-------------------------------------------------------------------------------
Статусы

Planned      — запланирована

In Progress  — находится в разработке

Active       — используется

Deprecated   — устарела

Removed      — удалена

Главное правило

PROJECT_REGISTRY является официальным перечнем компонентов проекта.

считается несуществующей с архитектурной точки зрения.
