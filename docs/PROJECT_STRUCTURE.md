# HashCenter Project Structure

Version: R0.1

-------------------------------------------------------------------------------
# Назначение

Данный документ описывает структуру проекта HashCenter.

Он является справочником для разработчиков и ИИ.

Перед созданием нового файла необходимо определить:

- существует ли уже подходящий пакет;
- соответствует ли изменение архитектуре;
- не создаёт ли изменение дублирование.

-------------------------------------------------------------------------------
# Общая структура

cmd/
    Точка входа приложения.

internal/
    Вся внутренняя логика проекта.

pkg/
    Переиспользуемые структуры и библиотеки.

web/
    Пользовательский интерфейс.

configs/
    Конфигурационные файлы.

data/
    База данных.

uploads/
    Загруженные пользователем файлы.

results/
    Полученные результаты.

logs/
    Журнал работы приложения.

docs/
    Документация проекта.

# Добавление новой функциональности

Перед созданием нового файла необходимо проверить:

1. Нет ли уже похожего файла.
2. Нет ли существующего сервиса.
3. Нет ли существующего интерфейса.
4. Не нарушает ли изменение архитектуру.
5. Можно ли реализовать задачу без создания нового пакета.

Если ответ "Да" хотя бы на один из первых трёх пунктов — необходимо использовать существующую реализацию.

-------------------------------------------------------------------------------
# Правило минимальных изменений

Любое изменение должно:

- затрагивать минимальное количество файлов;
- использовать существующие структуры;
- использовать существующие интерфейсы;
- не создавать дублирование;
- не менять архитектуру без необходимости.
