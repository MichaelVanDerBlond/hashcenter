# HashCenter R0.2 Architecture

## Цели

R0.2 превращает HashCenter из набора независимых команд в полноценный центр управления задачами.

Основные возможности:

- История запусков
- Очередь задач
- Восстановление после перезапуска
- Pause / Resume / Cancel
- Live Dashboard
- Несколько Worker'ов
- Подготовка к распределённой обработке

---

# Основные сущности

## Session

Session является центральной сущностью системы.

Session описывает одну атаку целиком.

Хранит:

- ID
- состояние
- время создания
- время запуска
- время завершения
- backend
- capture file
- dictionary
- attack mode
- hash mode
- mask
- rule
- workload
- device
- session name
- статус hashcat
- exit code
- error

История отображается исключительно из Session.

---

## Queue

Queue хранит только управление выполнением.

Поля:

- id
- session_id
- state
- priority
- worker
- created
- started
- finished

Queue не дублирует параметры атаки.

---

## Worker

Worker получает Queue Item.

Далее:

Queue Item

↓

Session

↓

attack.Execute()

↓

jobs.Manager

↓

hashcat

---

## Web

Web UI работает только через Repository.

Никаких прямых обращений к runtime.

---

## Runtime

Runtime существует только во время выполнения.

После завершения уничтожается.

История хранится исключительно в SQLite.

---

## Repository

Все обращения к SQLite проходят только через Repository.

Никакой SQL внутри HTTP.
